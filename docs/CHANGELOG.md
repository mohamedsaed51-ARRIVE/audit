# سجل التغييرات — ARRIVE AUDIT CONTROL TOWER (V3)

كل بند هنا تغيير حقيقي تم تنفيذه واختباره فعليًا في هذا المستودع (لا يوجد بند "مخطَّط" أو "نظري"، وأي
بند لم يُنفَّذ بعد مذكور صراحة في `docs/security-risk-report.md` كخطر مفتوح بدل إدراجه هنا). العمود
"نتيجة الاختبار" يعكس آخر تشغيل فعلي لكل ملف اختبار ذي صلة، وليس ادّعاءً عامًا.

## 1) إعادة تسمية الأدوار: Branch Manager ← Senior Auditor، Viewer ← Audit Viewer

| الملف | الوصف | السبب |
|---|---|---|
| `backend/schema.json` | تغيير مفاتيح `role_permissions` فقط — القيم (actions/branchScope/canBeAssignedAllBranches/pages) لم تتغيّر في هذه الخطوة | النظام مخصَّص حصريًا لموظفي قسم التدقيق؛ لا يوجد دور لموظفي فروع فعليين، والاسم القديم "Branch Manager" كان مضلِّلًا |
| `appsscript/Code.gs` | إعادة تضمين `SCHEMA` + تحديث كل التعليقات المرجعية | تطابق مع schema.json |
| `dashboard/index.html` | تحديث قوائم الأدوار المنسدلة والجدول التعريفي الثابت | تطابق الواجهة مع الأدوار الفعلية |
| كل ملفات الاختبار | استبدال كل مرجع للاسمين القديمين | منع بقاء مراجع ميتة تُربك القراءة لاحقًا |

**نتيجة الاختبار**: تحقُّق شامل بعد التغيير — 250/250 (رقم تلك الجولة قبل الإضافات اللاحقة).

## 9) إصلاح: `SESSION_TTL_SECONDS` كانت تتجاوز الحد الحقيقي لِـ `CacheService`

| الملف | الوصف | السبب |
|---|---|---|
| `appsscript/Code.gs` | `SESSION_TTL_SECONDS`: `8 * 60 * 60` (28800) ← `21600` (6 ساعات — الحد الأقصى الحقيقي الموثَّق لِـ `CacheService.put()` في Google Apps Script) | القيمة القديمة كانت ستُسبِّب خطأ وقت تشغيل حقيقي عند كل عملية تسجيل دخول على منصة Apps Script حقيقية — عطل لم يكتشفه أي من الاختبارات الـ272 السابقة |
| `appsscript/gs_sandbox.js` | تعزيز محاكي `CacheService`: تسجيل TTL الفعلي لكل `put()`، رفض أي قيمة خارج 1–21600 (يرمي خطأً يحاكي رفض المنصة الحقيقية)، محاكاة انتهاء صلاحية زمنية فعلية، أدوات اختبار (`__cacheTestHooks`) لفحص TTL المخزَّن ومحاكاة انتهاء الكاش حتميًا | إغلاق فجوة الاكتشاف التي سمحت لهذا العطل بالمرور عبر 272 اختبارًا سابقًا دون أن يُلاحَظ |
| `appsscript/test_session_ttl.js` (جديد) | 20 اختبارًا: قيمة الثابت، عدم قراءة TTL من الطلب، فرض المحاكي للحد الحقيقي، TTL الفعلي المخزَّن = 21600، لا كلمة مرور في بيانات الجلسة، Token غير صحيح/مفقود مرفوض، انتهاء الكاش يُبطل الجلسة، Logout يُبطل فورًا، لا Fail-Open | إثبات الإصلاح وحراسته من التكرار |
| `dashboard/index.html`, `appsscript/test_security_v2.js` | تحديث نص "8 ساعات" ← "6 ساعات" في الواجهة وتعليق اختبار | تطابق التوثيق مع القيمة الفعلية |

**نتيجة الاختبار**: 20/20 (جديد) + إعادة تشغيل كامل الحزمة القديمة بلا أي تراجع.

## ملاحظة ختامية إلزامية

**لم يُشغَّل أي بند في هذا السجل على Google Apps Script حقيقي منشور أو على Google Sheets حقيقية.**
كل "نتيجة اختبار" أعلاه Sandbox (Node.js عبر `vm` يُشغِّل `appsscript/Code.gs` الفعلي) أو Playwright
(متصفح حقيقي، ضد نفس المحاكاة لا ضد Web App منشور فعليًا). راجع `docs/security-risk-report.md` (البند
12) للتفصيل الكامل حول هذه الفجوة والخطوات المطلوبة لسدّها قبل أي اعتماد إنتاجي.
